LINE Front-end Framework

Warikan-kun LIFF Launcher

提案フォームと応募フォームの LIFF 導線を切り出した、LINE 版の初期実装です。 このページ自体はランチャーとして使い、各画面は個別 LIFF URL として登録します。

使い方

  1. `assets/config.js` に LIFF ID と API Base URL を設定する
  2. `publicBaseUrl` を Pages の公開 URL に合わせる
  3. Cloudflare Pages などで `/line-liff/` を配信する
  4. LINE Developers Console で Proposal / Apply 用 LIFF アプリを登録する
  5. n8n 側で `profile/bootstrap`, `proposal/create`, `products/search`, `application/upsert` を有効化する
主催者提案フォームを開く 応募フォームを開く

前提 URL

  • Proposal LIFF URL: `/line-liff/proposal.html`
  • Apply LIFF URL: `/line-liff/apply.html?managementId=...`
  • n8n API 例: `/api/liff/profile/bootstrap`, `/api/liff/proposal/create`, `/api/liff/products/search`, `/api/liff/application/upsert`
