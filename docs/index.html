LINEグループ共同購入OS

募集・応募・支払い案内を3タップへ。

Warikan-kun は、学生グループの共同購入から面倒を消すサービスです。 主催者は募集を作るだけ。参加者は欲しい数を押すだけ。支払い以降は個別に進めます。

Origin

快適さと楽さに対価が生まれる。

Warikan-kun の価値は割り勘計算ではなく、説明、数量確認、催促、支払い案内、気まずさをまとめて消すことです。 機能を増やすより、考えなくていい時間を増やします。

入力させない

案件ID、名前、LINE IDは可能な限り自動取得。参加者には数量だけを選ばせます。

公開と個別を分ける

募集と応募はグループ、支払いと証跡は個別。便利さと空気の両方を守ります。

戻れる

再応募は数量更新。個別に送れない時は友だち追加へ。失敗しても戻れます。

Flow

人の動線はLINE中心。

Host

商品名、金額、個数、締切を入れて募集カードを作る。

Group

botがグループに募集カードを投稿。参加者の最初の操作は「欲しい」だけ。

Apply

1個、2個、3個はチャット内で保存。その他だけ専用画面で入力する。

個別案内

支払い案内、催促、証跡、完了通知は個別に送る。

Processing Core

処理は商用コアへ。

LIFF / LINE 入口と最短操作に専念
warikan-api proposal, application, payment, notification, audit を所有
PostgreSQL Google Sheets から取引台帳を移行
Event Workers 通知、決済照合、催促、分析を非同期化
Roadmap

GMV10億円は通過点。

MVPは検証速度を優先します。PMF後は取引台帳、決済、監査、通知を本番基盤へ移し、GMV100億円以上を狙える会社価値に接続します。

Phase 0

LINE版MVPで応募率、再利用率、支払い完了率を見る。

Phase 1

`warikan-api` と PostgreSQL に商用コアを切り出す。

Phase 2

PayPay/PSP決済、webhook、照合、返金、消込を持つ。

Phase 3

監視、分析、CS、不正対策、イベント基盤を拡張する。
